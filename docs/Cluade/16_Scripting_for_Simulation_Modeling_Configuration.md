# Topic 16: Scripting for Simulation, Modeling and Configuration of Cellular Systems

**Q1.** What is the output of `print(2**3)` in Python?
A) 6  B) 8  C) 5  D) 9
**Answer: B) 8**
**ব্যাখ্যা:** `**` মানে power।

**Q2.** What is the output of `print(7//2)` in Python?
A) 3.5  B) 3  C) 4  D) 2
**Answer: B) 3**
**ব্যাখ্যা:** `//` floor division; `%` modulus (7%2 = 1)।

**Q3.** What is the output of `sum(range(5))`?
A) 10  B) 15  C) 5  D) 4
**Answer: A) 10**
**ব্যাখ্যা:** range(5) = 0,1,2,3,4; যোগফল = 10।

**Q4.** Which library is most commonly used for numerical arrays in Python?
A) NumPy  B) Flask  C) Tkinter  D) Pygame
**Answer: A) NumPy**
**ব্যাখ্যা:** SciPy ও Matplotlib সিমুলেশন ও প্লটের জন্য সাথে ব্যবহৃত।

**Q5.** Free-space path loss (dB) = 20log10(d_km) + 20log10(f_MHz) + 32.44. For d = 1 km and f = 1000 MHz, FSPL is:
A) 92.44 dB  B) 32.44 dB  C) 60 dB  D) 120 dB
**Answer: A) 92.44 dB**
**ব্যাখ্যা:** 0 + 60 + 32.44 = 92.44 dB।

**Q6.** Which discrete-event network simulator supports LTE/5G modules?
A) ns-3  B) Photoshop  C) VLC  D) Excel
**Answer: A) ns-3**
**ব্যাখ্যা:** OMNeT++, MATLAB ও Simu5G-ও প্রচলিত।

A) Open5GS and free5GC  B) OpenOffice  C) OpenCV  D) OpenGL
**Answer: A)**
**ব্যাখ্যা:** RAN/UE সিমুলেশনে srsRAN বা UERANSIM ব্যবহৃত।

**Q8.** Which tool automates network device configuration using YAML playbooks?
A) Ansible  B) Paint  C) Notepad  D) WinRAR
**Answer: A) Ansible**
**ব্যাখ্যা:** NETCONF/YANG model-driven configuration-এর মান।

**Q9.** Which command searches text patterns in Linux?
A) grep  B) mkdir  C) cd  D) chmod
**Answer: A) grep**
**ব্যাখ্যা:** `tail -f` লাইভ লগ দেখায়, `awk`/`sed` টেক্সট প্রসেস করে।

**Q10.** The first line of a bash script `#!/bin/bash` is called:
A) Shebang  B) Header  C) Comment only  D) Footer
**Answer: A) Shebang**
**ব্যাখ্যা:** কোন interpreter চালাবে তা নির্ধারণ করে।

**Q11.** Which protocol is widely used to monitor network devices?
A) SNMP  B) FTP  C) POP3  D) SMTP
**Answer: A) SNMP**
**ব্যাখ্যা:** Simple Network Management Protocol, MIB ও OID ব্যবহার করে।

**Q12.** Monte Carlo simulation is based on:
A) Repeated random sampling  B) Fixed values  C) Manual testing  D) Analog circuits
**Answer: A)**
**ব্যাখ্যা:** fading, user drop, coverage ইত্যাদির পরিসংখ্যানগত ফলাফল পেতে ব্যবহৃত।
